= Haven documentation

Haven is a personal agent system built around Hermes, with WhatsApp text and inbound Czech voice messages as its planned phone interface. The first deployment will use one Ubuntu VPS and bounded automation. Nora is the coordinator's working name.

The local foundation is accepted through a fresh checkout: public sources, a private-instance template, configuration v1 validation and a documentation/check workflow. The existing Ubuntu pilot also has accepted private administration, independent model authentication and a supervised coordinator. WhatsApp pairing, voice quality and off-site restore remain later H1 work.
