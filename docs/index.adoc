= Haven documentation

Haven is a personal agent system built around Hermes, with WhatsApp text and inbound Czech voice messages as its planned phone interface. The first deployment will use one Ubuntu VPS and bounded automation. Nora is the coordinator's working name.

The local foundation is accepted through a fresh checkout: public sources, a private-instance template, configuration v1 validation and a documentation/check workflow. Hermes deployment, real Codex authentication, WhatsApp pairing and voice quality remain unverified integrations.
