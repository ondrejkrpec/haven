= H1.9: Storage and monitoring options

Checked against official sources on 2026-10-30. After this comparison, the owner selected link:h1.9-scaleway-healthchecks.adoc[Scaleway Object Storage + hosted Healthchecks.io]; provisioning and live acceptance remain pending. This comparison is not an order or an account-specific quote. Prices below describe storage only, before taxes unless stated; USD and EUR are deliberately not converted. Volume means the entire retained repository, not the size of one daily backup. Confirm billable rounding, minimum invoice/payment rules and actual account terms before ordering.

Backblaze's https://www.backblaze.com/blog/backblaze-pricing-and-product-updates/[2026-03-17 update] establishes the May 1 pricing/API change; older help pages about per-call charges should not override it. The primary pricing page's free-storage wording was not established by the retrieved live page, so the table does not subtract it.

For a small Haven-only repository, compare Scaleway when an EU-operated service matters most, R2 EU when staying within a free allowance matters most, and B2 EU for its storage pricing. Storage Box becomes more interesting when the owner also wants substantially more backup capacity. These are tradeoffs; credentials, deletion protection and an actual restore still require acceptance on whichever provider is selected.

== Independent monitoring

[cols="1,2,2",options="header"]
|===
|Candidate |Verified public offer |Fit
|https://healthchecks.io/pricing/[Healthchecks.io Hobbyist]
|USD 0/month, 20 jobs, 100 log entries per job.
|Focused https://healthchecks.io/faq/[dead-man heartbeat monitoring]; https://healthchecks.io/docs/signaling_failures/[explicit failure signals] are supported. Two checks can cover backup completion and a combined service/backup-freshness heartbeat. Keep ping URLs private and send no raw logs.
|https://betterstack.com/uptime[Better Stack Uptime]
|10 monitors, 10 heartbeats and one status page with three-minute checks advertised free.
|An alternative if one console should also cover other public services. Heartbeats still work without exposing Haven's private dashboard. Account-specific notification/integration limits remain to verify.
|===

A monitor installed only on the Haven VPS cannot report that host's complete disappearance without an external receiver. This pilot does not add another self-hosted server just to run monitoring. Before accepting either hosted candidate, choose the owner's notification destination, confirm a real alert and exercise a deliberately missed heartbeat without disabling production access.
